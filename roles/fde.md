# FDE Rubric v1.1.0

## 10 秒看什么
- 客户/任务问题 → 生产结果闭环（非纯平台功能开发）  
- 端到端 Owner、混杂干系人、数据与现场约束  
- 工程基本功语言信号

## 必须证据

| ID | 必须证据 | 可观察检查 | 出处与证据等级 |
|----|----------|------------|----------------|
| FDE-EMBED | 嵌入客户现实、把问题当作自己的 | 是否出现客户/现场/驻场/业务问题陈述（可脱敏） | Palantir FDE JD https://jobs.lever.co/palantir/5168e8fd-fec1-4fea-b7a1-81bdaea65850｜**一手（招聘方 JD）** |
| FDE-E2E | 从首次客户对话到上线改变其运作的端到端所有权 | 是否有端到端项目 | 同上 Core Responsibilities｜**一手** |
| FDE-BUILD | 定制应用 / LLM workflow / 生产方案 | 有无交付产物类型 | 同上｜**一手** |
| FDE-STAKE | 从一线用户到高管的干系人 | 协作对象层级 | 同上｜**一手** |
| FDE-AMB | 不完整信息下决策、目标漂移中交付 | 有无歧义/迭代叙述 | What We Value｜**一手** |
| FDE-SEC | 安全编码/权限/隐私考量 | 安全相关一句 | What We Require｜**一手** |
| FDE-LANG | 至少一门列出的主力语言 | Skills 命中 | 同上｜**一手** |
| FDE-OUTCOME | （综合）可测客户结果 | 结果数字 | 将 JD「outcome」落到 G-XYZ｜**本 skill 综合** |

## 缺口声明
除 Palantir JD 与二手 FDE 攻略外，缺少「FDE 简历」独立一手白皮书；除 JD 条目外的简历句式依赖 G-XYZ/G-ACCOMPLISH。

## 常见差稿
- 纯 SWE 无客户结果；只写配置平台无使命指标

## 打分锚点
- 5：客户问题+ownership+生产结果  
- 3：有交付但偏内部开发口吻  
- 1：与 FDE 无关功能列表
